# SageStore | Plataforma de E-commerce

Projeto de e-commerce desenvolvido com **C# e ASP.NET Core MVC**, com foco em gerenciamento de produtos, administração da loja, integração com serviços externos e processamento de pedidos.

A SageStore foi desenvolvida como um projeto prático para aplicar conhecimentos de desenvolvimento web, integração de APIs e gerenciamento de banco de dados.

## 🖥️ Sobre o projeto

A SageStore é uma plataforma de comércio eletrônico que reúne funcionalidades para a exibição de produtos, gerenciamento administrativo e fluxo de compras.

## ⚙️ Tecnologias utilizadas

- **C#**
- **ASP.NET Core MVC**
- **ASP.NET Core Identity**
- **MySQL**
- **APIs REST**
- **HTML, CSS e JavaScript**

## ✨ Principais funcionalidades

- Catálogo e páginas de produtos.
- Painel administrativo.
- Autenticação e controle de acesso por permissões.
- Integração com APIs e serviços externos.
- Fluxo de checkout e processamento de pedidos.
- Integração com pagamentos via Pix.

## 🎯 Objetivo

Desenvolver uma aplicação que simule necessidades reais de um e-commerce, praticando arquitetura de aplicações web, persistência de dados, segurança e integração entre sistemas.
